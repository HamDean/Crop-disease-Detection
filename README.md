# 🌱 Crop Disease Detection System

An end-to-end machine learning project for detecting crop diseases using deep learning, deployed with a React frontend and a Hugging Face inference backend.

---

## 🚀 Overview

This project identifies plant diseases from images using a PyTorch + FastAI deep learning model.

It includes:
- Custom CNN model (FastAI, trained on plant disease dataset)
- Deployed API on Hugging Face Spaces
- React frontend built with Vite
- AI-powered treatment advice using the ChatGPT API
- Fully deployed frontend on Netlify

---

## 🧠 Features

### 🔍 1. Crop Disease Detection
Upload an image of a plant leaf — the model predicts the plant type and disease with confidence scores.

### 💡 2. Treatment Recommendation
Uses the ChatGPT API to provide:
- Explanation of the disease
- Treatment steps
- Prevention recommendations

### 🌐 3. End-to-End Deployment
- Frontend: React + Vite → Netlify
- Backend Model Inference: Hugging Face Spaces
- AI Suggestions: OpenAI ChatGPT API
- Server: Node/Express

### 🖼️ 4. User-Friendly Interface
- Image upload system
- Real-time predictions
- Clean and responsive design
